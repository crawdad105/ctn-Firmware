# Virtual Debugger
The virtual debugger is a console application (written in c# with dotnet 8.0 so it works on linux), that allows you to access 3d stuff.

It wasn't supposed to exist, and its main feature is a file manager which allows you to read and write files (not folders) to the 3ds whenever (ei. does not need you to open ftpd to send and receive files from a device).
It is a custom implementation and does not fallow any preexisting file protocol.
I have not had an issue with it yet but because of this if you have the options just use ftpd or a better file transferer.
